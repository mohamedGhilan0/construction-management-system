# Construction Management System

نظام إدارة مشاريع المقاولات والإنشاءات — API-first, bilingual Arabic/English, responsive and dark-mode ready.

## Stack
Next.js + TypeScript + Tailwind CSS. Supabase integration will be added for auth/database/storage.

## Development
```bash
npm install
npm run dev
```

## Lovable
GitHub is the source of truth. Lovable is intended as a preview/display surface only; code changes should be committed through this repository.
